# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Проект

«Дельта-v» — тактический бой кораблей в пустоте (дуэль или команды до 5 на 5, сетевая игра до 10 человек). Чистый JS на ES-модулях, Canvas 2D, без сборки и без npm-зависимостей. Код, комментарии и тесты пишутся на русском; сообщения коммитов — короткие, на английском.

## Команды

- `make run` (или `npm start`) — дев-сервер на http://localhost:8080, `make run PORT=3000` — другой порт. Используйте его, а не `python -m http.server`: `scripts/serve.mjs` отдаёт всё с `Cache-Control: no-store`, иначе браузер смешивает старые и новые модули.
- `make test` (= `npm test`) — все тесты (`node --test tests/*.test.js`).
- Один файл: `node --test tests/weapons.test.js`; один тест по имени: `node --test --test-name-pattern="часть имени" tests/ui.test.js`.
- Группы: `make test-sim`, `make test-net`, `make test-e2e`, `make test-ui`.
- `make check` — `node --check` всех модулей; `make ci` — check + test (перед коммитом).
- `?perf=1` в адресе показывает время `draw()` на карте; `?token=...` — токен брокера MQTT для сетевой игры.

## Архитектура

Слои и направление зависимостей: `sim` ← `net` ← `render`/`ui` ← `session`/`main`.

- **`src/sim/`** — детерминированная симуляция без DOM, запускается в Node. Всё состояние боя в одном объекте `S` (`state.js`, `export let S`); `newGame()` заменяет `S` целиком, остальные модули видят замену через живую привязку импорта — не кэшируйте `S` и его поля между кадрами. Шаг фиксированный (`DT` в `config.js`), `step()` в `world.js`. Публичный API — `src/sim/index.js`. Все единицы СИ; баланс в `src/config.js`.
  - Приказы (`orders.js`) исполняются с задержкой реакции экипажа, а не сразу.
  - Сенсоры (`sensors.js`): `S.tracks[o][e]` — что корабль `o` знает о противнике `e`; двигатель с `accG > 0.3` виден на любой дистанции, иначе — только ближе `DETECT`. Потерянный контакт ведётся по баллистике. Рендер показывает мир глазами `viewShip()` (свой корабль, после гибели — живой союзник).
  - Эффекты кладутся через `addFx()` в `S.fx` с `id`, `t0`, `dur` (игровое время).
  - Сообщения экипажу — ключи словаря через `sayTo(id, key, params)`, а не готовый текст.
- **`src/net/`** — сеть через MQTT (брокер flespi, библиотека грузится с CDN при первом подключении). Хост считает симуляцию и шлёт каждому гостю отдельный снимок (`snapshot.js`) — только то, что видит корабль гостя. Гость применяет снимок и между снимками летит по инерции (`guestStep`). Новые эффекты и облака шариков отдаются каждому гостю по одному разу по `id`. Состав боя (слоты) — `src/roster.js`.
- **`src/render/`** — Canvas 2D, чистое отображение: в `S` не пишет. `scene.js` собирает кадр; эффекты ведутся в реальном времени отдельным реестром (`fx.js`, `WeakMap` по объектам `S.fx`, часы `clock.js`), подписи идут через очередь с приоритетами (`labels.js`), силуэт ↔ подробная модель — `lod.js`. Цвета только в `theme.js` (для CSS — переменные в `styles/main.css`). Модули рендера не трогают `document`/`window` при импорте: холсты создаются лениво — тесты импортируют их в Node (`paintSphere`).
- **`src/ui/`**, `session.js`, `main.js` — DOM, управление, оверлей старт/итог и игровой цикл (`frame()`: `simTick` → `easeZoom` → `draw(dtReal)` → `updateHud`).
- **i18n** (`src/i18n.js`, словари `src/i18n/en.js`, `ru.js`): любой текст интерфейса и карты — через `t('ключ', params)`; новый ключ добавлять в оба словаря. Итог боя и сообщения хранятся как `[ключ, параметры]`, чтобы гость видел их на своём языке.

## Тесты

- Тесты симуляции используют `tests/helpers.js` (`emptySpace()` и т. п.).
- Тесты интерфейса и сети поднимают всю игру в Node: сначала импорт `tests/dom-stub.js` (DOM и canvas-заглушка, элементы берутся из настоящего `index.html`; `dom.frame()` — один кадр, `dom.drawn` — всё, что нарисовано `fillText`), затем `await import('../src/main.js')`. Сеть — `tests/fake-mqtt.js`; `mp-e2e` запускает хост и гостей в отдельных потоках через `tests/e2e/`.
- Окно итога появляется через `RESULT_DELAY` (`src/session.js`); тесты, ждущие итог, завязаны на эту задержку.
